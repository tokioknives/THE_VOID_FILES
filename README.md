# The Conspiracy Files

An open, interactive conspiracy archive. Spin the globe, fly into a case, and explore a retro room full of documents, computers, and clues.

Every case is labeled **documented** (government records confirm it) or **disputed** (official story vs. claims).

## Add a new case
Open `index.html`, find `const CASES=[`, copy one case block, and change the name, lat/lon, and objects.

## Add archive files
Put PDFs in the `archive/` folder and add a line to `FILES` in `index.html`.

## Turn on the chat
Uses [Giscus](https://giscus.app) (free, powered by GitHub Discussions). Enable Discussions in repo Settings, install the Giscus app, fill in the form at giscus.app, and paste the values into `GISCUS` in `index.html`.
